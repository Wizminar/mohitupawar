A bit about me

I'm in the first batch of the Bachelor of Cybersecurity programme at IIT Kanpur. Thirty-odd of us, a brand new degree, and no senior batch to ask for directions.

I like understanding technology beyond the surface: how systems are designed, how they break, and how they can be made better. Cybersecurity is where I've started, mostly web security, Linux and the systems underneath, but I see it as a way into computing as a whole.

I got here through web development. HTML, CSS and JavaScript first, then a growing curiosity about how the web actually works, then the question of what keeps it secure, private and trustworthy. These days I learn by building small tools and taking them apart.

Outside class I'm usually at a student meeting, on a football pitch, or holding a Rubik's cube. I'm still figuring out where I want to specialise, and I'm enjoying that part.

the name WizMinar? a gaming username I made up when I was 11. I still don't know what it means. wizminar.com is where I post about tech.

p. 3

Things I built

Three small tools I made to understand security and privacy by actually implementing them. Each one is live, and the source is open.

Sentinel

Security headers are the cheapest defence a website has, and the easiest to forget, because nobody sees them. Sentinel checks a site for six of them (CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy and Permissions-Policy), marks each as present, weak or missing, and explains in plain English what it protects against.

sentinel.mohitupawar.com

Try Sentinel Read the source

built this while learning what a CSP even is.

Cipher

A password checker that measures strength in bits of entropy rather than "has a symbol". It shows why a long passphrase beats a short scramble, and checks for known breaches using k-anonymity, so your password never leaves the browser.

cipher.mohitupawar.com

Try Cipher Read the source

length × log₂(pool). that one line changed how I make passwords.

Permute

Most online file converters upload your file to someone else's server. Permute converts files right in your browser, so nothing is uploaded. You don't have to trust me on that: open the network panel and watch.
